# 🖥️ 中醫資訊系統 - 前端與行政管理介面 (UI & Admin)

> 本模組為中醫資訊系統（TCM Microservice System）的使用者介面與行政管理端。採用前後端分離架構，提供醫師臨床診斷操作與行政人員資料管理介面，並包含前端專屬之 API 轉發與後端資料整合邏輯。

---

## 🛠️ 核心功能與開發重點 (Key Features)

* **醫師與行政管理介面：** 提供病歷登錄、藥材庫存查詢、處方簽開立等視覺化操作畫面。
* **前後端 API 整合 (BFF / Backend Integration)：** 包含前端專屬的輕量後端/轉接邏輯， API 資料格式轉換以及與微服務 Gateway 之對接。
* **身份驗證與路由保護：** 配合後端 API 進行 Token / Session 驗證，確保行政管理權限之安全性。

---

## 🛠️ 技術棧 (Tech Stack)

* **前端框架/技術：** HTML5, CSS3, JavaScript (或你採用的前端框架)
* **後端與整合介面：** Java / Spring Boot 
* **API 溝通：** RESTful API, Axios
